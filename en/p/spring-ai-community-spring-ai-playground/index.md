# spring-ai-community/spring-ai-playground

Safe local execution layer for AI agent tools. Build and test-run MCP tools (no pass, no run), serve them from a built-in MCP server, and use them in Agentic Chat with RAG, human-in-the-loop approval, and built-in observability. Cross-platform desktop app powered by Spring AI.
