# lhfer/image-fingerprint-remover

Strip EXIF, GPS, C2PA / Content Credentials, AI watermarks, and Stable Diffusion / ComfyUI / Midjourney / ChatGPT prompt blocks from any image. Three modes: safe (pixel-identical), paranoid (re-encode), nuclear (disrupt SynthID/Digimarc). CLI + macOS desktop app. 100% offline.
